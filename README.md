# Calculator

A simple command-line calculator built with Maven, JUnit 5, and Apache Commons Lang.

[![Java CI with Maven](https://github.com/zhaoyuge0507/calculator/actions/workflows/ci-calculator.yml/badge.svg?branch=main)](https://github.com/zhaoyuge0507/calculator/actions/workflows/ci-calculator.yml)

## Build

mvn clean test
mvn package

## Run

java -cp target/calculator-1.0-SNAPSHOT.jar com.zhaoyuge.App 2 + 2
